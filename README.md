# Next Item Recommendation using TLSAN

This project implements a Time-aware Long and Short-term Attention Network (TLSAN)
for next-item recommendation.

## Features
- Long-term and short-term attention modeling
- Time-aware position embeddings
- Compared with PACA baseline

## Tech Stack
- Python
- PyTorch
- Pandas, NumPy
- Scikit-learn

## Results
TLSAN achieved ~0.98 AUC on Amazon Movies & TV dataset.
